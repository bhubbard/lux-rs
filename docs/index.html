Architecture & Pipeline 🏗️

1. URL Router
(av/BV/ep regex, domain match)
➔
2. Extractor
(Bilibili, YouTube, Douyin, HTML5)
➔
3. Metadata Engine
(DASH streams, XML danmaku)
➔
4. Chunk Downloader
(HTTP/2, resume, indicatif)
➔
5. Stream Muxer
(zero-copy copy, .ass subtitle)

Installation & Usage 🚀

# Install via Cargo
cargo install --git https://github.com/bhubbard/lux-rs

# Inspect video formats without downloading
lux -i "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Download 1080P with 8 threads & Danmaku converted to .ass
lux -s 80 --threads 8 "BV1xx411c7mD"

# Universal HTML5 video grabber
lux -o ./movies "https://example.com/stream-page"
