lux-rs — Concurrent Multi-Platform Media Stream Extractor & Downloader in Rust

lux-rs is a lightweight, 100% safe Rust rewrite of the lux media downloader for extracting video and audio streams from online platforms. It features async multi-chunk HTTP range downloading, automatic playlist traversal, and zero-copy stream muxing in a single static binary.

Installation & Usage 🚀

# Install via Cargo
cargo install --git https://github.com/bhubbard/lux-rs

# Inspect video formats without downloading
lux -i "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Download 1080P with 8 threads & Danmaku converted to .ass
lux -s 80 --threads 8 "BV1xx411c7mD"

# Universal HTML5 video grabber
lux -o ./movies "https://example.com/stream-page"
